# PS4 firmware 14.02 compatibility notes

**Status: research only — no 14.02 runtime compatibility has been verified by this project.**

This document separates three different questions:

1. Can we compile a PS4 homebrew application?
2. Can a particular console firmware launch that application through an already-supported development environment?
3. Can an application replace or modify the retail PS4 system interface?

These are not the same capability. A successful compile does not prove that a retail console on firmware 14.02 can install or launch the result, and a normal application cannot replace the system shell.

## What the public references say

- The [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain) is an open-source toolchain for building PS4 homebrew without Sony's proprietary SDK. Its documentation describes headers, library stubs, tools and sample projects. It does not establish that every firmware version is supported.
- The [PS4 payload SDK firmware list](https://github.com/ps4-payload-dev/sdk) lists supported firmware revisions through 13.04 in the version reviewed for this note. It does not list 14.02.
- The [ConsoleMods PS4 FAQ](https://consolemods.org/wiki/PS4%3AFAQ) makes a broader claim about firmware coverage through 14.02. That claim does not, by itself, establish that this repository's application can run on 14.02.

Because these public references do not agree on the practical support boundary, this project treats 14.02 as **unverified** until there is a reproducible, independently documented test for the exact console and application environment.

## Project plan

1. Keep the existing web dashboard as the visual and interaction prototype.
2. Separate platform-independent UI logic from any future native rendering layer.
3. Investigate documented, legitimate homebrew development interfaces and toolchain requirements.
4. Build and test a harmless native dashboard sample in an appropriate development environment.
5. Record exact hardware, firmware, toolchain version, build result and runtime result separately. Never mark a firmware as supported based only on compilation.

## Explicit non-goals

This project will not implement a jailbreak, kernel exploit, privilege escalation, authentication bypass, console-identity spoofing, or PSN circumvention. It will not claim to replace the PS4 system shell or globally capture the reserved PS button.
